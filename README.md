 :- Seasonal Vaccine Adoption Prediction

A machine learning project that predicts whether individuals will receive a seasonal flu vaccine based on demographic, health, and behavioral factors.

:- Overview

This project analyzes vaccine adoption patterns using supervised learning techniques on a dataset of 4,757 respondents with 30+ features. 
Multiple classification models were trained and evaluated to identify the most effective predictor.

:- Key Features

* Exploratory Data Analysis (EDA)
* Data preprocessing and feature engineering
* Logistic Regression, Random Forest, Gradient Boosting, and XGBoost models
* Model evaluation using Accuracy, Precision, Recall, and ROC-AUC
* Feature importance analysis

:- Key Findings

Factors with the strongest influence on vaccine adoption:

* Doctor recommendations
* Age group
* Vaccine effectiveness beliefs
* Health insurance status
* Perceived flu risk

:- Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, XGBoost

:- Results

The project compares multiple machine learning models and identifies the best-performing approach for predicting seasonal vaccine adoption.
